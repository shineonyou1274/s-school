# 김해은혜학교 AI 실습 연수

교사용 AI 실습 안내 페이지입니다.

- 1부: 바이브코딩으로 연습 앱 만들기
- 2부: NotebookLM으로 긍정적 행동지원(PBS) 자료 만들기
- 3부: AI 에이전트로 체험학습과 여행 계획 세우기

## 보기

https://shineonyou1274.github.io/s-school/

`index.html`을 브라우저에서 바로 열어도 사용할 수 있습니다. 복사 버튼, 단계 이동, 글자 크기 조절, 전체 인쇄를 지원합니다.
