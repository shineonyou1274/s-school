# 김해은혜학교 AI 실습 연수

교사용 AI 실습 안내 페이지입니다.

- 1부: 바이브코딩으로 연습 앱 만들기
- 2부: NotebookLM으로 긍정적 행동지원(PBS) 자료 만들기
- 3부: AI 에이전트로 체험학습과 여행 계획 세우기

## 보기

https://shineonyou1274.github.io/s-school/

`index.html`을 브라우저에서 바로 열어도 사용할 수 있습니다. 복사 버튼, 단계 이동, 글자 크기 조절, 전체 인쇄를 지원합니다.

## 실습 자료

교육청이 공개한 예시 자료이며, 드라이브 폴더 링크는 페이지 안에 있습니다.

## 개인 학습 기록

- 각 단계에 텍스트 메모와 손필기를 남기고 책갈피로 다시 찾을 수 있습니다.
- 본문 글자를 골라 형광펜이나 밑줄을 칠할 수 있습니다. 칠한 곳을 누르면 표시를 지울 수 있고, 단계별로 저장되어 새로고침해도 남으며 백업 파일에도 들어갑니다.
- 15개 실습 단계의 완료를 직접 표시합니다. 각 단계를 처음 완료하면 원숭이에게 바나나를 건네는 짧은 애니메이션이 나옵니다(소리 없음, 같은 단계는 한 번만, 움직임 줄이기 설정에서는 정지 화면). 각 부와 전체를 처음 마치면 짧은 축하 화면이 나타납니다.
- `내 기록`에서 메모·책갈피·진행 상황을 모아 보고 JSON 파일로 백업하거나 복원할 수 있습니다. 메모와 손필기를 따로 인쇄할 수도 있습니다.
- 기록은 현재 브라우저의 localStorage(`s-school-records-v1`)에만 저장하며 서버로 전송하거나 기기 간 자동 동기화하지 않습니다. 여러 탭에서는 항목별 변경을 병합하고 전체 삭제를 함께 반영합니다.
- 브라우저 데이터를 지우면 기록도 사라집니다. 필요한 기록은 먼저 내려받으세요. 학생 실명 등 민감한 정보는 적지 마세요. 공용 PC에서는 `내 기록 → 기록 백업과 관리 → 이 브라우저의 내 기록 지우기`를 실행하세요.
- 저장 공간이 없거나 브라우저 저장이 차단되면 저장되지 않았음을 표시합니다. 이때는 기록 파일을 내려받아 보관하세요.
- 외부 글꼴이 늦게 응답해도 기능이 먼저 실행되며, 글꼴을 불러오지 못하면 시스템 글꼴로 표시합니다.
